# qfield-plugins

Samling av QField-plugins.

| Plugin | Beskrivning | Ladda ner |
|---|---|---|
| [line-distance](line-distance/) | Live-avstånd till linje/polygon: offset, längs linjen till A/B, höjdskillnad | [line-distance-v0.2.0.zip](https://github.com/jockesv/qfield-plugins/raw/main/line-distance/dist/line-distance-v0.2.0.zip) |

## Installera i QField
Plugin-hanteraren → *Installera plugin från URL* → klistra in nedladdningslänken ovan (eller välj zip-filen lokalt), och aktivera pluginet.

## Struktur
Varje plugin ligger i egen mapp med `main.qml`, `metadata.txt`, `README.md` och färdigbyggd zip i `dist/`.
